# Rate Repository App

A Full Stack Open React Native application for rating GitHub repositories.

## Features

- User authentication (sign in, sign out)
- Repository list with infinite scroll pagination
- Repository details view with reviews
- Create reviews for repositories
- "My Reviews" page to see your own reviews
- Persistent login state using AsyncStorage
- Platform-specific fonts and styling
- Responsive design for mobile and web

## Technologies

- React Native (Expo SDK 55)
- Apollo Client (GraphQL)
- React Router Native
- Formik & Yup (validation)
- AsyncStorage (token storage)
- Jest & React Native Testing Library (testing)
